#  ToDo – Task Management App

A clean and intuitive Flutter-based ToDo application designed for managing daily tasks with simplicity and efficiency. This app demonstrates state management, responsive UI, and persistent data handling in Flutter.

---

##  Purpose

This project was built to explore:
- Flutter UI design principles
- State management techniques
- Task management workflows
- Local storage and user interaction

---

##  Tech Stack

- **Flutter**
- **Dart**
- **State Management:** Provider

---

##  Features

- Add, update, and delete tasks
- Mark tasks as completed
- Clean, responsive UI
